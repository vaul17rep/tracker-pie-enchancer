# Tracker Pie Customizer

An Obsidian plugin that customizes pie chart labels generated by the Tracker plugin.

## Features

- Customize inner pie chart labels
- Customize external labels
- Automatically redistribute overlapping external labels
- Hide small categories below a configurable percentage
- Hide corresponding arrows for hidden categories
- Customize legend font size
- Optionally display percentages in the legend
- Automatically adjust label text color for better contrast

## Requirements

This plugin requires the Obsidian Tracker plugin.

## Installation

The plugin is currently available for manual installation.

1. Download `main.js`, `manifest.json` and any required files from the latest release.
2. Create a folder named `tracker-pie-customizer` inside your Obsidian vault:

   `.obsidian/plugins/tracker-pie-customizer/`

3. Put the downloaded files into that folder.
4. Enable **Tracker Pie Customizer** in Obsidian's Community Plugins settings.
